# Bookmark Manager

A web application for managing bookmarks with advanced search functionality and ability to combine bookmarks related to one person or company. Developed with FastAPI.


## Build Instructions

1. Create a virtual environment: `python -m venv ./venv`

2. Activate the virtual environment: 
    - In Linux: `source venv/bin/activate`
    - In Windows: `.\venv\Scripts\activate`

3. Start the server: `fastapi run`

4. Go to the provided address, e.g. `http://127.0.0.1:8000/scalar`
